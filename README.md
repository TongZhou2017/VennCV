# VennCV

VennCV 把一个课题组里常要一起看的事情放在同一份工作区里：研究领域和项目、论文从构思到发表、作者和实验室、合作关系、待办，以及基金的申报和结题。维恩图用来看领域怎样交叉、项目落在哪里；时间线、人物和基金则用来把这些工作按时间和责任串起来。

---

## 安装

普通使用请到 [Releases](https://github.com/TongZhou2017/VennCV/releases) 下载对应系统的安装包。跨平台安装包由 GitHub Actions 在发布版本时生成，并放到同一个 Release 里。

| 系统 | 安装包 |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` |
| macOS（Intel） | `.dmg` |
| Windows | 安装包 |
| Linux | `.deb` 等 |

下载与本机系统相符的那一份，按系统提示安装后打开即可。尚未配置代码签名时，第一次打开可能会看到系统的安全提示，确认来源后继续安装。

安装包和从源码打开用的是同一份本机数据：

| 系统 | 默认位置 |
| --- | --- |
| macOS | `~/Library/Application Support/VennCV` |
| Windows | `%APPDATA%\VennCV` |
| Linux | `$XDG_DATA_HOME/VennCV`，未设置时为 `~/.local/share/VennCV` |

可用环境变量 `VENNCV_DATA_DIR` 改到别的目录。登录页也可以在常用的用户数据路径之间切换。

## 从源码运行

参与开发，或想在浏览器里直接打开当前代码时，需要 [Node.js](https://nodejs.org/) 20 或更高版本。桌面窗口还需要 Rust 和 [Tauri 的系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
git clone https://github.com/TongZhou2017/VennCV.git
cd VennCV/web
npm install
npm run dev
```

终端里会给出本地地址，多为 [http://127.0.0.1:5173](http://127.0.0.1:5173)。在项目根目录执行 `npm install` 后，再用 `npm run tauri:dev` 可以打开桌面窗口。构建、打包和排错见 [Wiki](https://github.com/TongZhou2017/VennCV/wiki)。

## 第一次打开

登录页按用户分卡片。点一张卡片，再输入密码。还没有密码的用户会标明「待设密码」，首次至少 4 位。可以勾选记住登录，3 天内再点这张卡片不必输入密码。新建用户在卡片列表末尾。一台电脑上可以有多个用户，数据彼此分开。

## 能支持的科研工作

**看清课题组在做什么。** 用领域和项目整理课题版图。一个项目可以同时属于几块领域，项目之间可以记下先后、依赖或相关关系。完成度和状态用来区分已发表、投稿中、正在推进和尚未开始的工作。

**把一篇论文跟到发表。** 每个项目可以记下预期完成、投稿期刊、预印本和正式发表，以及收稿、返修、接收这些时间点。时间线按日期把这些事情排开，也能回到全部时间。发表记录可以填入作者、文章类型和基金号。

**管好人和实验室。** 人物库记下姓名、职位、单位和在实验室里的身份。学生、博后、科研助理和 PI 可以放在同一个实验室里；一个实验室有多位 PI 时，再指定学生的导师。合作视图按共同项目把人连起来。实验室可以生成自己的主页，列出成员、项目和投稿。

**把基金和成果对上。** 申报时从已有论文里选代表作和项目基础成果。结题时按基金号汇总已经发表的工作。待办可以挂到某一项基金上，时间线上也能单独看这项基金。

**每天推进，也能换电脑接着做。** 待办记在项目上，也能从合作网络里按人查看。工作区可以导出、导入 JSON。需要几台电脑一致时，可在登录页接上坚果云：填写邮箱和应用密码，再打开某个用户的上传。应用密码在坚果云的安全选项里生成。

画面怎么拖动、缩放和出图，打开软件后看工具栏里的帮助。

## 数据与隐私

- 工作数据在这台电脑的用户库里。换浏览器不会丢掉账号和工作区。
- 换电脑时，用软件里的导出，到新环境再导入；或使用上面的坚果云同步。默认同步是关闭的。
- 少数界面偏好留在当前窗口，不写进工作区文件。

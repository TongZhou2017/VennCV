# VennCV

用**维恩图式**的大圆、小圆和连线，把科研里的**研究领域**、**具体项目**以及**项目之间的关系**放在一张图上管理。你可以一眼看到进展、状态和重点，适合整理课题、论文与协作任务。

---

## 安装说明（请先读这一段）

**目前还没有通过 GitHub Releases 提供现成的安装包**（`.exe` / `.dmg` / `.AppImage` 等）。若你打开 [Releases](https://github.com/TongZhou2017/VennCV/releases) 页面是空的或没有附件，属于正常情况。

在此情况下，要使用本软件，需要先在电脑上**从源码启动**（步骤在下面）。这要求你能：

- 会使用终端（命令行）执行几条命令；
- 能安装 **[Node.js](https://nodejs.org/)（建议 20 或更高版本）**。

若你希望**以后只要下载安装包、双击即用**，请关注同一仓库的 **Releases**；一旦有维护者上传发行版，优先用那里的说明安装即可。

## 普通用户怎么用：推荐从浏览器里打开（步骤最少）

界面主要在 **网页**里运行，不打包桌面程序也能完整使用（数据保存在本机浏览器里）。

1. **安装 Node.js**  
   打开 [https://nodejs.org/](https://nodejs.org/)，下载并安装 **LTS** 版本。装好后打开终端，执行 `node -v`，应显示 `v20` 或更高。

2. **拿到本项目的代码**  
   若会用 Git：在终端执行  
   `git clone https://github.com/TongZhou2017/VennCV.git`  
   然后 `cd VennCV`。  
   若不会 Git：在 GitHub 仓库页点 **Code → Download ZIP**，解压后进入解压出的文件夹（其中应能看到 `web` 文件夹）。

3. **安装依赖并启动**  
   下面三行请**按顺序**在终端里执行（可直接全部复制粘贴；**前提**：当前目录是「含有 `web` 文件夹的项目根目录」。若你已经在 `web` 文件夹里，则删掉第一行 `cd web` 再执行后两行）。

```bash
cd web
npm install
npm run dev
```

   - **`cd web`**：进入前端工程目录。  
   - **`npm install`**：安装依赖，**第一次**或依赖更新后需要执行，等待结束即可。  
   - **`npm run dev`**：启动开发服务；成功后终端里会出现本地访问地址。

4. **用浏览器打开**  
   终端里一般会提示本地地址（多为 **http://127.0.0.1:5173**）。用 Chrome、Edge、Safari 等打开该地址，即可开始使用。

5. **关闭软件**  
   在运行 `npm run dev` 的终端窗口按 **Ctrl+C** 停止服务；浏览器里关掉标签页即可。

> **说明**：这种方式下，你的数据在**当前这台电脑、当前浏览器**的本地存储里，清除站点数据或换浏览器可能看不到原数据，重要内容请用软件里的**导出**做备份（见下文「备份」）。

## 可选：想打开「桌面窗口」时（难度更高）

若希望像普通桌面软件一样有独立窗口（菜单栏、系统托盘等），需要在本机额外安装 **Rust** 以及 Tauri 所需的系统组件，步骤较多。适合愿意折腾环境的用户。

1. 完成上一节 **Node.js** 与 **项目代码** 的准备。  
2. 在**项目根目录**（与 `web` 文件夹同级、能看到根目录的 `package.json` 的那一层）打开终端，**依次执行**：

```bash
npm install
npm run tauri:dev
```

3. 首次运行会编译较久；成功后会出现桌面窗口，界面与浏览器版一致。

更细的环境要求（各操作系统要装哪些库）见 **[Tauri 官方说明](https://v2.tauri.app/start/prerequisites/)**。若命令报错，可到仓库 **[Wiki](https://github.com/TongZhou2017/VennCV/wiki)** 或 Issue 里查找或提问。

## 你能用 VennCV 做什么

- **管理领域与项目**：左侧列出「领域」和「项目」，点选即可在右侧查看和编辑。  
- **看图说话**：大圆表示研究领域，小圆表示项目；**实线 / 虚线箭头**表示项目之间的关系；颜色和图例帮助区分**完成度**与**进行状态**。  
- **编辑详情**：在右侧属性区修改名称、描述、状态、所属领域等；可管理**项目之间的关系**（类型、标签、线型等，以软件内界面为准）。  
- **整理画布**：拖动画布平移视图，用滚轮缩放；支持选中、多选以及批量操作（具体以工具栏与侧栏提示为准）。  
- **备份与交换数据**：通过软件内的**导入 / 导出**（通常为 JSON）保存或分享你的工作区内容。

## 日常操作建议

| 你想做的   | 可以试着这样 |
| ---------- | ------------ |
| 选中一个项目 | 在画布上点小圆，或在左侧列表中点项目名称 |
| 改项目内容 | 选中后看右侧「属性」面板 |
| 移动画布 | 在空白处拖动 |
| 放大缩小 | 鼠标滚轮，或使用工具栏上的缩放相关按钮 |
| 备份 | 浏览器使用方式下，数据在**本机浏览器**；重要资料请定期用软件内**导出**保存到文件 |

常用快捷键与常见桌面软件类似：**保存、撤销、重做、新建** 等多为 **Ctrl**（苹果电脑上多为 **⌘**），具体以菜单与界面提示为准。

## 图上的「状态」是什么意思

界面上的中文名称以软件内显示为准，常见含义包括：

| 界面上可能看到的说法 | 大致含义 |
| -------------------- | -------- |
| 已发表 | 已有正式发表成果 |
| 投稿中 | 稿件已投出、在审或等待结果 |
| 优先做 | 当前阶段优先推进 |
| 稳步做 | 按计划持续推进 |
| 待启动 | 尚未正式开始 |

## 数据与隐私（简要说明）

- 本软件主要在**你的电脑或浏览器本机**保存工作数据，**不会**默认把课题内容上传到云端（除非你自行使用导出文件并通过其他方式发送）。  
- 换电脑或换浏览器时，请使用软件提供的**导出**，在新环境再**导入**。  
- 若使用**多用户**登录，不同用户的数据相互分开，适合一台电脑上多人各用各的。

**推送到 GitHub 时**：浏览器里的数据在 **localStorage**，不在仓库目录里，**不会**随 `git push` 上传。仓库根目录若生成了 `users/`、`config.yaml`、`app_settings.yaml` 等，已在 [`.gitignore`](.gitignore) 中排除。提交前仍建议用 `git status` 看一眼，**不要**把自行导出到项目文件夹里的 JSON 等用 `git add -f` 强行加入。
